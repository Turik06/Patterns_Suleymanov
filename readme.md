| Наименование сущности | Описание | Связи с другими сущностями |
|---|---|---|
| **Единица измерения** (`Unit`) | Простая сущность. Мера веса или объёма: граммы, литры, штуки. | `Ингредиент` (ассоциация), `Группа` (агрегация) |
| **Деньги** (`Money`) | Простая сущность. Сумма и валюта для цен и расчётов. | `Блюдо / Номенклатура блюд` (ассоциация), `Контракт` (ассоциация) |
| **Ингредиент** (`Ingredient`) | Простая сущность. Продукт с указанием количества и меры. | `Единица измерения` (ассоциация), `Блюдо / Номенклатура блюд` (агрегация), `Технологическая карта` (ассоциация), `Склад` (ассоциация) |
| **Адрес / Адрес доставки** (`Address`) | Простая сущность. Местоположение ресторана или клиента для доставки. | `Ресторан` (композиция), `Заказ` (ассоциация) |
| **Сотрудник** (`Employee`) | Простая сущность. Работник компании. | `График работы` (агрегация), `Контракт` (агрегация), `Ресторан` (агрегация) |
| **Контрагент** (`Contractor`) | Простая сущность. Поставщик продуктов или партнёр компании. | `Группа` (агрегация), `Контракт` (агрегация) |
| **Группа** (`Group`) | Простая сущность. Категория для объединения похожих объектов. | `Единица измерения` (агрегация), `Контрагент` (агрегация), `Группа` (ассоциация) |
| **Блюдо / Номенклатура блюд** (`Dish`) | Комплексная сущность. Позиция меню с ценой и списком продуктов для приготовления. | `Ингредиент` (агрегация), `Деньги` (ассоциация), `Технологическая карта` (композиция), `Ресторан` (агрегация) |
| **Технологическая карта** (`Recipe`) | Комплексная сущность. Рецепт с точным весом ингредиентов и шагами готовки. | `Ингредиент` (ассоциация), `Блюдо / Номенклатура блюд` (композиция), `Технологическая карта` (ассоциация) |
| **Склад** (`Storage`) | Комплексная сущность. Место хранения запасов продуктов и заготовок. | `Ингредиент` (ассоциация), `Ресторан` (композиция), `Заказ` (ассоциация) |
| **Ресторан** (`Restaurant`) | Комплексная сущность. Точка сети со своим складом, меню и персоналом. | `Адрес` (композиция), `Склад` (композиция), `Блюдо / Номенклатура блюд` (агрегация), `Сотрудник` (агрегация), `Заказ` (ассоциация) |
| **Контракт** (`Contract`) | Комплексная сущность. Договор с поставщиком на закупку продуктов. | `Контрагент` (агрегация), `Сотрудник` (агрегация), `Деньги` (ассоциация) |
| **График работы** (`WorkSchedule`) | Комплексная сущность. Расписание рабочих смен сотрудников. | `Сотрудник` (агрегация) |
| **Заказ** (`Order`) | Комплексная сущность. Заказ клиента со списком блюд и адресом доставки. | `Ресторан` (ассоциация), `Склад` (ассоциация), `Блюдо / Номенклатура блюд` (агрегация), `Адрес / Адрес доставки` (ассоциация) |
